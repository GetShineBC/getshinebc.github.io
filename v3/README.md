# ShineIQ Market Atlas V3 — Return on Cost

V3 is a standalone, single-map adaptation of the existing public V2, with no changes to V1 or V2.

## Formula

Annual return on cost (%) = [2025 EIA retail-equivalent value ($/kW DC/year)] / [$2.76/Wdc × 1,000 Wdc/kWdc] × 100.

Installed cost is **$2,760 per kW DC** in all counties. For example, $338 / $2,760 × 100 = **12.2%**. The metric is annualized (per year) and assumes 100% of modeled output is valued at the selected sector's 2025 average retail benchmark. It is not actual owner bill savings, financial ROI, IRR, payback, or net return.

Data, map colors, utility-method distinctions, filters, and county click behavior are inherited from the published V2 source as of November 4, 2026. The only public map lens is Combined Retail Value; other dashboard views and rankings are not presented. The main green county card emphasizes annual return on cost and shows annual retail value beneath. The hover tooltip shows both.
